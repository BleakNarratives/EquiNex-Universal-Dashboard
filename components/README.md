# /components

This directory contains all the modular React components that make up the EquiNex Universal Dashboard UI.

## Component Overview

-   **`App.tsx`**: The root application component, handling top-level state and layout.
-   **`AutonomousOperative.tsx`**: The UI for the A.D.E.P.T. autonomous AI, displaying its status, analysis, and action log.
-   **`BiometricConsentModal.tsx`**: The initial consent screen required for application access.
-   **`Dashboard.tsx`**: The main container for all dashboard widgets and views.
-   **`ErrorBoundary.tsx`**: A robust error boundary to catch and gracefully handle runtime errors.
-   **`FileIntegrityMonitor.tsx`**: Displays the status of critical system files and alerts on tampering.
-   **`FloatingOrbMenu.tsx`**: The primary user interaction orb for settings and voice assistant activation.
-   **`GlobalAlert.tsx`**: A system-wide banner for displaying critical security alerts.
-   **`Header.tsx`**: The main header, displaying the application title and current persona/theme.
-   **`MetricCard.tsx`**: A reusable card for displaying a single key metric.
-   **`ModuleStatusTable.tsx`**: A table that shows the real-time status of all backend modules.
-   **`SecurityAuditLog.tsx`**: A dedicated, scrolling log for security-related events.
-   **`SettingsModal.tsx`**: A modal window for application configuration.
-   **`SystemHealth.tsx`**: A prominent banner displaying the overall system health status.
-   **`SystemLog.tsx`**: The swipe-able view for detailed, verbose system event logs.
-   **`TermuxTerminal.tsx`**: The interactive command-line interface with NLP capabilities.
-   **`TrafficAnalysis.tsx`**: Visualizes real-time network traffic and simulated DDoS mitigation.
-   **`VoiceAssistant.tsx`**: The interface for the live, conversational AI, showing transcriptions.
